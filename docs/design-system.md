# 디자인 시스템

## 방향

대시보드보다 얇은 디지털 문제집에 가깝게 만듭니다. 문제와 선지가 가장 먼저 보이고, 반복해서 읽는 동안 장식이나 성과 지표가 집중을 빼앗지 않도록 합니다. 카드 나열·그라데이션·마스코트·진한 그림자·배지 남발은 사용하지 않습니다. 밝은 테마만 제공합니다.

## 색상

| 용도             | 값        |
| ---------------- | --------- |
| 바깥 배경        | `#F5F6F8` |
| 읽기 면          | `#FFFFFF` |
| 본문             | `#20242B` |
| 보조 글자        | `#5C6470` |
| 구분선           | `#DDE1E6` |
| 활성·링크        | `#2457A7` |
| 선택 배경        | `#EDF3FB` |
| 중요 형광펜      | `#FFF0B3` |
| 반대·예외 형광펜 | `#FBE0E3` |

색만으로 상태를 구분하지 않습니다. ‘읽음’, ‘헷갈림’, ‘정답가안’, ‘법령·판례 변경’은 글자로 표시합니다. 상태 확인을 점수·정답률과 혼동시키지 않습니다.

## 글자와 간격

Pretendard 자체 호스팅. 문제·선지·해설 기본 18px, 줄높이 1.8. 16/18/20px를 선택할 수 있습니다. 본문 폭 최대 760px, 데스크톱 좌우 여백 64px, 모바일 20px. 제목 24px/600, 메타데이터 12~13px. PDF의 물리적 줄바꿈은 읽기 화면에서 연결하되 원문 저장 데이터는 보존합니다.

간격은 4/8/12/16/24/32/48/64px. 문제 사이에 여백과 1px 선만 사용합니다. 버튼 반경 5~6px, 설정 창 10px. 고정 상단 56px, 데스크톱 목차 232px. 1024px 미만에서는 목차를 대화상자로 옮깁니다.

## 구성 요소

- 상단: 이름·과목, 읽기 모드, 범위와 설정
- 목차: 단원, 현재 회독 읽은 수, 다음 회독
- 문제: 시험 정보 → 질문·보기 → 선지 → 정답 → 해설 → 공식 근거 → 학습 상태
- 설정: 글자 크기·정답 가리기·압축 보기·암호화 백업
- 형광펜: 텍스트 선택 시에만 작은 도구 표시, 표시 클릭/키보드로 삭제

회독률은 학습 진도이지 숙련도 평가가 아닙니다. 익숙함과 읽음을 분리하고 같은 화면에서 상태를 되돌릴 수 있게 합니다. 확인이 필요한 원문과 해설은 조용히 숨기지 않습니다.

## 접근성과 검수

의미 있는 버튼·라벨·제목·목록, native dialog의 초점 처리, 키보드 포커스 선을 사용합니다. 모바일 주요 조작은 44px 높이를 기준으로 합니다. 강제 애니메이션·다크 모드·장식용 이미지는 없습니다. 360/390/768/1024/1440px와 확대 화면에서 가로 넘침을 점검합니다.
