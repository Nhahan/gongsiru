# 공시루

문제와 선지를 눈으로 읽고 반복하는 개인 학습 사이트입니다. 앱 코드는 공개하고 학습 자료는 브라우저에서 복호화합니다.

## 사용

개인 학습 링크로 접속합니다. **링크를 가진 사람은 누구나 내용을 열 수 있으므로 공유하지 마세요.** 열쇠 없는 주소에서는 잠금 화면만 보입니다.

- 이어 읽기 / 한 문제씩 보기
- 단원·시험·급수·연도별 범위, 익숙한 문항 접기
- 문장 선택 → 중요 / 반대·예외 형광펜. 표시를 누르면 삭제
- 익숙한 정도와 읽음 표시를 독립적으로 기록
- 회독 범위 고정, 다음 회독에서 읽음만 초기화
- 이 브라우저의 암호화 기록, 파일 백업·복원

문제의 공식 정답, 원문 교정, 해설 근거 대조, 현행법 검토는 **서로 다른 상태**입니다. 미검증 문항·초안을 검증 완료로 취급하지 않습니다. 원래 시험 문제와 정답은 당시 기준을 보존합니다.

## 개발

Node.js 24 이상, npm을 사용합니다.

```sh
npm ci
npm run dev
npm test
npm run check:public
npm run build
```

암호화 자료는 저장소에 있지만 복호화 키는 없습니다. 개발 중에도 별도로 보관한 학습 링크의 키가 필요합니다. CI에는 키를 등록하지 않습니다.
